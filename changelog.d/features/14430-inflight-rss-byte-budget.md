- Add an opt-in estimated-RSS ledger for concurrent SSE holds (#14430). Disabled by default; set `OMNIROUTE_CHAT_FLIGHT_BUDGET_ENABLED=true` to enable. The provisional model reserves 50% of effective memory (clamped to 256 MiB–4 GiB), charges `max(body bytes × 4, budget / 100)`, returns 413 above `budget / 4`, and returns immediate 503 `flight_bytes_budget` on saturation. Multiplier requires production RSS validation before opt-in; mixed-Accept local usage commands stay uncharged. ([#14430](https://github.com/diegosouzapw/OmniRoute/pull/14430))
