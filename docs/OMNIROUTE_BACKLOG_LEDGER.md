# OmniRoute backlog integration ledger

Single tracking file for upstream PRs, issues, discussions, and local integration evidence.

## Status rules

- **Committed; validation pending**: a local commit references this ID. This does not prove full upstream parity, acceptance criteria, tests, or deployment.
- **Considered; unverified**: referenced in a saved worker report; source mapping and applicability still need verification.
- **Not reviewed**: present in the downloaded inventory, without recorded review evidence.
- Do not repeat completed review without a reason: changed upstream revision, failed tests, regression, or changed requirements. Pending validation is not duplicate review.
- Only mark **Implemented; verified** after source comparison and relevant passing tests are recorded.
- No deployment/reload is authorized. i18n remains last priority.

- **Rejected** requires a per-item reason and evidence; unreviewed, blocked, or low-priority items are not rejected. **Implemented; verified** requires the correction commit and passing test command/result, not merely a clean git diff.
