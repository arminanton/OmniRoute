# Decision register

- **D1:** Keep three MaxAI evidence boundaries separate: native extension layouts 1/2/3/4/6; a distinct host-shim council with a seven-seat `parallel=7` outer trace, committed 12-seat aggregate/driver, and configurable local ceiling 30; and the exact 30/32 episode, which remains owner-attested and missing. None sets provider capacity, and greater-than-six behavior is not disproven.
- **D2:** Every future MaxAI lane is one ordinary single chat. It must use unique run/lane/turn/attempt identity, mode-correct conversation/message/parent IDs, one private stream accumulator, and the hardened normal-chat provider-exposed reasoning parser. No batch endpoint or reduced parallel parser is inferred.
- **D3:** UC TTS and STT are deferred/OFF and excluded from core/live validation because they consume AI credits.
- **D4:** No remote repository is created or pushed without explicit approval.
- **D5:** Saved Free/Mistral catalog data is archaeology, not a new route. `mistral-7b-instruct-free` used the normal chat path historically, but current backend identity, automatic free-mode mapping, and extension exclusivity are unproved. Do not add an endpoint or silently make the model routable.
